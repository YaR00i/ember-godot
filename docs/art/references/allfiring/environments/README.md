# ALLfiring — референсы окружения

Сохранено по просьбе автора 2026-10-14. Только изображения окружения:
без рекламного текста, логотипов и крупных портретов персонажей.
Источник — [официальный сайт ALLfiring](https://allfiring.genmugame.com/).

- [Каменный двор](stone-courtyard.png): широкие лестницы, крупные архитектурные
  массы, локальные акценты и читаемый центральный путь.
  [Исходное изображение](https://allfiring-en-gm-cdn.genmugame.com/official/images/p3-p1.png).
- [Ледяная пещера](ice-cavern.png): многоуровневая воксельная поверхность,
  спокойные холодные массы и редкие световые акценты.
  [Исходное изображение](https://allfiring-en-gm-cdn.genmugame.com/official/images/p3-p2.png).
- [Сад с красными деревьями](red-tree-garden.png): разделение пути и окружения,
  крупные цветовые пятна и ясные силуэты деревьев.
  [Исходное изображение](https://allfiring-en-gm-cdn.genmugame.com/official/images/p3-p3.png).

Это опубликованные изображения окружения; в них нет персонажа для замера роста.
Они помогают обсуждать композицию, крупность масс и палитру, но не доказывают
метры, плотность вокселей или настройки обычной игровой камеры ALLfiring.
Это референсы для обсуждения окружения, не игровые ассеты Ember.
Файлы сохранены без изменения. URL и SHA-256 — в [sources.json](sources.json).
