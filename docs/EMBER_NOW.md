## Активная цель

**Подготовить большую карту и планер генерации по частям.** По просьбе автора
приоритет переключён с художественной приёмки материалов. Выбран ориентир
острова 256–512 м, затем рост по замерам; блок/персонажи сохраняют масштаб.
Адресные участки, генератор одной области, региональная подготовка воды и экран
загрузки F6 приняты автором; занятая земля и авторские настройки сохраняются.
Дальность водных shader-деталей принята; кэш статических береговых полей реализован.
Ручная приёмка кэша берегов OPEN: повторный F6 сохранённой карты,
берег/пена/мокрый след после правки и Undo.
Native команды/Save/Reopen/F6 корректны; cold editor timing gate OPEN (105,8 мс
при пороге 100 мс после sleep), причина пика не изолирована; детали — документ воды.
Точная и дальняя геометрия земли/воды реализованы только в игре, ручной gate OPEN.
Near вода, берег/струя, стыки и физика точные; editor jobs отсутствуют. Общий
worker готовит LOD при загрузке, камера не делает remesh; native/targeted PASS.
Runtime-кэш geometry/LOD реализован: near/physics точные, local invalidation,
безопасный fallback, editor без cache/jobs. Targeted и native editor + два F6 PASS.
Большая проба: обычная подготовка 19,72 с, пустой cache 26,69, готовый 4,89;
это geometry benchmark, не полный игровой startup. Первый запуск дороже.
Ближайшее действие — авторский F6 дважды после Save, затем local edit/Undo:
берег/набег/водопад, материалы, стыки, приближение/отдаление. Ручной gate OPEN.
Замеры и цена старта — Water Rendering/Terrain Authoring. Следующий отдельный
срез — оценка невидимых участков/загрузки по расстоянию. Streaming не начат. Порядок — World
Authoring Architecture → «Производные данные и стоимость эффектов».
После исправления sectioned-кисти автор сообщил улучшение и отложил остаточную
задержку редактора. Её ручной gate OPEN; gameplay оптимизация не должна возвращать
тяжёлую подготовку на brush input. Owners, замеры и ограничения — Terrain Authoring;
заполненные 256–512 м/слабый ПК OPEN.
Точка возврата: compact-карта → «+ Участок» → выделить пустое место или несколько
квадратов → «Далее: рельеф и вода» → preview/Apply, кисти, Ctrl+Z/Y, Save/Reopen/F6.
Рельеф уже созданной земли: «Ограничить участок» → «Сгенерировать рельеф…».

Живая опора остаётся открытой; при работе с адресными участками проверить:
живые кисти, создание/расширение, материалы, объекты и Save/Reopen/Discard.

полный цикл сохранения, узкое окно 1280×720/125%, паттерны/швы, повторный кэш
миниатюр, плавность создания/расширения и самостоятельная оценка открытия карты.

Первое действие возврата: выбрать один незакрытый сценарий на текущей
landscape_compact или тестовой 4×4/5×4 карте, сверить раздел темы и его gate.
