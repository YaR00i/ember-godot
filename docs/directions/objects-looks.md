# Объекты и облики
Обновлено: 2026-10-22. Активность: в очереди (после «Текущего мира»).

## Цель
Любой объект Source получает любой облик (воксели / low poly / подробный) через один вход
«Source → форма и материал». Физика, пол и навигация остаются на одной поверхности.

## Владельцы
- Камень (твёрдая оболочка): `scripts/ember_voxel_solid_surface.gd` (оболочка, живые грани, воксельный вид,
  `AUTHORED_BLOCK_M`), `scripts/ember_voxel_prop.gd` (переключатель видов, масштаб мира, пол),
  `scripts/ember_voxel_prefab.gd`, `scripts/ember_voxel_model_resource.gd`, `scripts/vox_mesher.gd`.
- Source и производные: `content/voxel_models/*.tres`, `prefabs/voxels/`.
- Деревья: `scripts/prototypes/ember_tree_*`, `addons/ember_import/ember_voxel_*tree*`.

## Принято автором
- Камень `vox_painted_rock_group`: рамка по силуэту, рисунок привязан к объекту, клавиши 4/5/6; подробный = low poly +
  глубина из рисунка (C2, 20 мм) + живые грани (вариант O1, 30 мм). Решение 22.10: «оставляем 30 мм».

## Сделано без приёмки
- Камень в игровой карте `landscape_compact` (масштаб 16 ед./блок): исправлена ошибка масштаба, вид проверен на кадрах.

## Открыто
- Новую твёрдую форму из частей **нельзя создать в редакторе**: `solid_surface` делает скрипт `tools/publish_rock_shape.gd`,
  такой объект один.
- Выпуклая оболочка на часть: арка/проём под мостом заполняется; мост собирается из выпуклых частей в одном Source.
- Слой «облики» отдельно для камня, дерева и земли; дерево не получает виды камня. Единый интерфейс — долг.
- Движение камеры/мерцание глубины, низкие углы, слабый ПК (глубина ≈ +0.8…1 мс на моей видеокарте), вытяжка рисунка
  на крутых скосах. Вид по умолчанию в карте — low poly (переключателя в карте нет).
- 23 модели Source нигде не используются (остатки редактора, 8 МБ).

## Где остановились
Камень стоит в карте. Дальше: (1) кнопка редактора «твёрдая форма из частей»; (2) единый вход облика для дерева;
оба — после того как карта соберётся (world-map.md).
