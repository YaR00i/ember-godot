# Ember — карта документации

Обновлено: 2026-09-30. Это короткий маршрутизатор, а не список обязательного чтения.

## Вход в задачу

1. ../AGENTS.md — правила; EMBER_NOW.md — активный срез и точка возврата.
2. Выбрать **одно направление** ниже; сначала найти заголовки или owner через rg.
3. Прочитать выбранный раздел и необходимые зависимости, найти код и targeted tests.
4. EMBER_WORKFLOW.md → «Контракт текущего среза» — согласовать изменения.

Очередь целей: EMBER_PRODUCT_PLAN.md → «Рабочая последовательность».
Для синхронизации без чтения всего проекта: EMBER_TECHNICAL_HANDOFF.md →
«Краткий контекст для синхронизации», затем NOW и только выбранная тема.
В том же чате не перечитывать неизменное. Новый чат сверяет актуальность входа.
Противоречие или изменение зависимости — основание расширить чтение.

## Что обновлять после работы

- NOW: активная цель, ближайшее действие, точка возврата, открытые решения;
  около 80 строк. Не история и не полный список систем.
- Product Plan: порядок результатов и масштаб; GDD: игровые правила/канон.
- Тематический документ: действующее поведение и ограничения своей темы.
- Technical Handoff: технические owners и контракты; test plan: сценарии проверки.
- README: маршруты. Страницы Space: краткий обзор и ссылки, без второго канона.

Одна истина в одном месте; соседний документ ссылается. Заменять статус, не
дописывать хронологию/повторные PASS. Новые документы — только для долговечной темы.
Git хранит историю; незакоммиченный исходник перед сокращением сохранить отдельно.

## Дальнейшее сокращение

GDD, Inspector Design, handoff и test plan остаются справочниками. Вход к ним —
через разделы выше, не чтение целиком. При следующей работе в теме выделять
действующее, удалять повторы лишь после сохранения у owner. Два тематических
входа земли и воды уже выделены из NOW; подробности не возвращать обратно.
