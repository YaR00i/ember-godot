# Ember — кисти мастерской

Статус: фазы 1–3 и двухэтапное выделение реализованы в рабочем дереве и ждут совместной ручной приёмки;
автоматические проверки не заменяют пользовательскую оценку. UI checkpoint:
`48774a0`.

## Ближайшая совместная проверка

Этот короткий маршрут сохранён для следующей сессии с пользователем. Подробные
краевые случаи остаются ниже в разделах инструментов и в `MIGRATION_TEST_PLAN.md`.

### 1. Процедурный куст

- [ ] Открыть `Штамп → Библиотека → + Новый источник → Куст`. Шесть типов
  источников должны читаться в сетке без обрезанных названий.
- [ ] Сравнить высоту 4/10/24, размах 2/6/12, стебли 1/6/12, пышность и
  неровность 20/60/100. Куст остаётся низким и широким, не превращается в
  уменьшенное дерево и не распадается на несвязанные куски.
- [ ] Задать заметно разные цвета стеблей и листвы. `Другой вариант куста`
  меняет силуэт, а боковая миниатюра показывает до четырёх форм набора.
- [ ] Сохранить 4–6 форм. Карточка обозначена как куст; `Редактировать`
  восстанавливает рецепт, закрытие без сохранения его не меняет.
- [ ] Через `Выбрать` поставить один куст. До Enter виден только черновик, Enter
  применяет его и оставляет куст выбранным; Ctrl+Z/Ctrl+Shift+Z работают.
- [ ] Провести `Россыпью` по ровной и ступенчатой земле с выключенным и
  включённым `Облегать рельеф`. Проверить предложенный шаг, разные формы,
  `Другой вариант`, один общий Undo и неизменность уже поставленных кустов после
  правки библиотечного рецепта.

### 2. Процедурная трава

- [ ] Открыть `+ Новый источник → Трава`. Сравнить высоту 2/6/12, размах
  1/2/4, 2/8/16 травинок, разброс высоты и наклон 0/50/100; проверить два
  контрастных цвета и до четырёх форм в боковой миниатюре.
- [ ] Сохранить 1/4/8 форм. `Выбрать` впервые открывает `Россыпь` с предложенным
  шагом; дальнейшие настройки этого источника помнятся до закрытия Canvas.
- [ ] Провести по ровной и ступенчатой верхней поверхности. Каждый пучок целиком
  привязывается корнем к локальной земле и остаётся вертикальным; боковая грань
  честно отклоняется. Внутренняя деформация `Облегать рельеф` для травы скрыта,
  чтобы не складывать наклонные травинки по отдельным voxel-колонкам.
- [ ] До Enter Resource не меняется; Enter применяет всю россыпь, одна Undo
  возвращает её. В F6 персонаж проходит через траву, а земля под ней сохраняет
  коллизию. Edit/reopen/discard рецепта не меняют уже нанесённую траву.

### 3. Двухэтапное выделение

- [ ] Выбрать `Выделение → Два этапа` и начать сверху. Протянуть плоскую область:
  до отпускания виден только голубой preview, прежнее выделение и модель не
  меняются. После отпускания рамка остаётся зафиксированной.
- [ ] На втором этапе вести мышь внутрь модели по перпендикуляру к первой грани.
  Проверить глубину 1/2/8, точный ввод числа, второй клик и Enter. Оранжевое
  итоговое выделение появляется только после подтверждения.
- [ ] Повторить с четырёх боковых сторон и снизу: плоскость следует первой грани,
  а второй этап идёт внутрь именно по её оси. При почти прямом взгляде на грань
  глубина регулируется вертикальным движением мыши или точным числом.
- [ ] Проверить `Новое`, `+ Shift`, `− Ctrl`: модификатор зажимается до первого
  нажатия. Весь двухэтапный жест даёт одну Undo-команду; Undo/Redo не меняют
  геометрию. Esc на любом этапе и смена инструмента отменяют только черновик и
  сохраняют прежнее выделение.
- [ ] Превратить итог в `Маску кисти`, затем лепить сверху и сбоку: направление
  маски берётся от начальной грани. Проверить перенос/копирование выбранного
  объёма и отсутствие регрессии обычной экранной `Рамки`.

### 4. Большое дерево как отдельный объект

- [ ] В нижней полке `Объекты` нажать `+ Большое дерево`. Сравнить высоты
  64/128/256, толщину ствола, размах и плотность кроны. До явного точного
  предпросмотра файлы и объект сцены не создаются; изменение параметра делает
  старый preview неподтверждённым.
- [ ] Создать дерево. Оно появляется одним объектом в `Map/Props` и обычной
  native-карточкой, а не штампом. Scene Undo/Redo снимает и возвращает instance;
  Save/reopen сохраняет результат.
- [ ] Открыть `Редактировать шаблон`, долепить и удалить несколько voxels,
  проверить Canvas Undo/Redo и Save/reopen. Затем создать независимый вариант
  через `Ещё… → Создать вариант из рецепта…`: прежнее дерево не меняется.
- [ ] В F6 пройти вокруг дерева: ствол и толстые ветви имеют collision, листва
  не образует невидимую стену. Сравнить масштаб 64 и 256 с малым stamp-деревом.

### 5. Короткая регрессия общего потока

- [ ] После куста снова выбрать обычный объёмный штамп, камень и малое дерево:
  `Один` и `Россыпь` по-прежнему дают preview → Enter → одну Undo-команду.
- [ ] Закрыть и снова открыть Canvas: библиотека, рецепты, цвета и наборы форм
  сохранены; уже поставленные voxels не меняются от последующего редактирования
  источника.
- [ ] Записать отдельно только различия игрового ощущения: слишком плотная
  россыпь, слабое разнообразие, неудобный диапазон параметров или заметная пауза.

## Цель

Самостоятельно создавать окружение: детали досок, сколы, бороздки, камни и берег.
Продолжить существующие кисти и новый UI, не создавать второй редактор.
Кисть меняет воксели модели; расстановка отдельных объектов сцены — отдельная
задача и не включается автоматически в этот план.

## Принятое поведение

По умолчанию один мазок наносит фиксированный слой: повторное проведение мышью
по тому же месту до отпускания кнопки не увеличивает толщину. Наращивание —
отдельный явный режим, а не скрытое следствие скорости мыши или FPS.
«Один слой» означает заданную глубину кисти, не всегда один воксель.
Новый мазок может добавить следующий слой. Для покраски правило означает
повторяемый результат без случайного накопления. `Рельеф` остаётся явно
обозначенным наращиванием, но его мазок фиксирует исходную поверхность при LMB:
созданный холм больше не перехватывает собственный raycast. Движение внутри одной
voxel-ячейки не перескакивает к пределу; удержание растёт по выбранному темпу, а
возврат в уже пройденную точку добавляет одну предсказуемую ступень до cap.
Свободный мазок по умолчанию следует видимым граням; при смене грани начинает
новый сегмент без пространственной перемычки. Альтернатива `Только одна грань`
фиксирует плоскость первой грани: луч курсора каждый раз проецируется обратно на
эту плоскость, а жест останавливается, когда под проекцией больше нет исходной
грани. Поэтому земля под висящим островком не продолжает мазок за его краем.
Другая сторона требует нового нажатия ЛКМ.
Направление свободного мазка берётся не из случайной грани одного вокселя, а из
усреднённой области исходной поверхности с удержанием выбранной оси. Отпечатки
ставятся по пройденному расстоянию относительно радиуса, поэтому редкие и частые
события мыши не меняют плотность мазка. Для `Добавить` точка также переносится по
усреднённой нормали: маленькая грань ступеньки не уводит кисть вбок.
Активная маска грани сильнее повторного попадания луча: её сохранённая знаковая
нормаль задаёт направление объёмной кисти. Поэтому выделенную боковую грань можно
удлинить наружу, даже если курсор на тонком ребре визуально попал в верхнюю грань.
`Сгладить` сохраняет локальный режим `Ступени` и получает отдельный `Общий
уровень`: медианная высота берётся из кольца вокруг отпечатка, выступы опускаются,
а ямки поднимаются при включённом тогле `Обрабатывать ямки`. Пустые сквозные
отверстия этот тогл не заделывает. Широкий мазок во время LMB показывает дешёвую
draft-сетку, а точная производная сетка достраивается после отпускания; медиана
берётся через гистограмму высот и разреженное устойчивое кольцо без сортировки.

`Рельеф` теперь сохраняет принятое поведение подрежимом `Наращивание` и имеет
отдельный `Генератор`. Генератор наносит закреплённый в координатах модели шум
`Почва` или `Гребни` с высотой, размером формы, детализацией, направлением
`Оба / Вверх / Вниз` и явной сменой варианта. Перед прежними плотными уровнями
`мало / средне / много` добавлен профиль `лёгкие`: он подавляет среднюю часть
шума и оставляет редкие мягкие гребни глубиной/высотой около 1–2 вокселей. Весь
LMB-жест использует одну
исходную поверхность и strongest influence на колонку: повтор внутри жеста и
частота событий не меняют результат. Генератор сохраняет хотя бы нижний воксель
занятой колонки и не пробивает случайные сквозные отверстия. Настройки остаются
editor-only профилем.

## 1. Доработка прежних инструментов

Сохранить лепку/удаление, покраску, материал, рельеф, площадку, сглаживание и склон.
Инвентаризировать фактические режимы: не считать отсутствующим уже реализованное.

- Чёткий контур затрагиваемых вокселей и видимое направление действия.
- Размер в вокселях отдельно от глубины; точные числа и понятная опора.
- Непрерывный путь без дыр при быстром движении; шаг не зависит от FPS.
- Фиксированный слой / наращивание обозначены явно.
- Сохранение настроек по инструментам, без случайного переноса чужих параметров.
- Согласованное поведение выделения, среза, скрытых и защищённых частей.
- Проверить сглаживание на тонких досках. Защита толщины — кандидат на отдельное
  решение после изучения алгоритма, не обещанная универсальная функция.

## 2. Две пользовательские кисти

### Паттерн с глубиной

Редактор плоской маски: рисование/стирание, размеры, толщина, поворот 90°,
отражение и опора. Добавление или вырезание отпечатка. Форма сохраняется в
библиотеке редактируемых пресетов; геометрия использует прежний voxel Resource.
Примеры: бороздка, скол, отверстие, бордюр. Не подменять бинарную маску
полутоновой картой высот без отдельного решения.

### Объёмный штамп

Продолжить существующий одиночный Add/Replace, палитру, каналы, повороты,
отражение, опору, редактирование геометрии через тот же Canvas.
Создание из выделения и существующей модели; повторяемое нанесение с шагом
в вокселях. Цвета источника сохраняются. Использование текущего цвета вместо
цветов штампа — полезный кандидат, согласовать отдельно, не менять default.
Пример: последовательность камней или креплений внутри модели.
Первый режим `Россыпь` наносит выбранный объёмный штамп вдоль мазка с заданным
шагом, поперечным разбросом и случайными поворотами 90° вокруг нормали первой
грани. Точки локально привязываются к поверхности. Seed фиксируется до preview,
кнопка `Другой вариант` меняет его без повторного рисования пути; результат
детерминирован и отменяется одним Undo. Набор из нескольких штампов остаётся
отдельным следующим улучшением. Опциональное `Облегать рельеф` проецирует нижнюю
точку каждого столбика штампа на исходную поверхность вдоль нормали первой грани
и сдвигает столбик целиком: толщина, цвета и каналы не растягиваются. `Изгиб ≤`
ограничивает поиск 1–8 vox и атомарно отклоняет слишком резкий перепад. До Enter
`Ctrl+Z`/`Ctrl+Shift+Z` убирают и возвращают по одному видимому шагу черновика;
после Enter вся россыпь остаётся одной обычной Undo-командой. Это не свободная
mesh-деформация и не отдельные scene props.

Третий режим объёмного штампа `Вдавить` зеркально направляет высоту занятой формы
внутрь нормали выбранной поверхности и очищает совпавшие воксели. Поэтому плоский
слой даёт неглубокий след, а высокие детали штампа — более глубокий рисунок.
Очищаются palette index, дополнительные voxel-каналы и part provenance; пустые
ячейки не считаются изменением. Режим работает для `Один`, `Путь`, `Линия` и
`Россыпь`; у россыпи совместим с `Облегать рельеф`. Preview удаления розовый,
commit атомарный и остаётся одной Undo-командой. Автоматический снежный бортик,
уплотнение материала и физика снега в этот срез не входят.

### Способы нанесения

Одиночный отпечаток, свободный мазок и прямая линия с preview до применения.
Прямая линия — для швов, балок и регулярных рядов. Не подразумевает автоматический
поворот штампа вдоль пути, деформацию формы или создание отдельных scene props.
Ориентацию по грани/фиксированной плоскости, поведение на углах, вне модели и при
пересечениях уточнить в контракте с простыми примерами. Нельзя наслаивать свежую
геометрию бесконтрольно: путь и фиксированную глубину считать относительно
согласованной исходной поверхности мазка, не постоянно меняющегося результата.

## 3. Общая безопасность и UX

- Один мазок/линия = один Undo; Esc отменяет незавершённое действие.
- Preview совпадает с применением, ошибки не оставляют частичный результат.
- Сохранить part provenance: новые voxels в active part/«Добавленное», удалённые
  не воскресают при разборе. Палитра/каналы/locks не теряются.
- Сохранить COW выбранного экземпляра, shared-edit предупреждения, save/reopen,
  discard, сценовое положение и актуальную collision.
- Настройки authoring не превращаются в новое gameplay-состояние.
- Вписать параметры в принятую мастерскую: активный инструмент слева,
  контекстные параметры, карточки библиотеки, короткие подсказки. Не возвращать
  длинные панели или вторую библиотеку с теми же данными.
- Большие мазки измерять на Причале: время расчёта, preview, commit, remesh,
  память. Не обещать отзывчивость по одному чистому plan benchmark.

## Порядок реализации

1. Короткий аудит прежних кистей и контракт общей семантики мазка; исправить
   выявленные несогласованности, проверить фиксированный слой и наращивание.
2. Непрерывный объёмный штамп с шагом и прямая линия; повторно принять одиночный.
3. Плоская маска с глубиной, её редактор и библиотечный lifecycle.
4. Совместная ручная приёмка, профилирование, документация и возврат в основной чат.

Не начинать все фазы одновременно. До каждой — фактические owners, границы,
критерии и короткое согласование, без повторного обсуждения уже принятых решений.
Если уточнение затрагивает ощущение кисти, показать пример, дать рекомендацию.

## Проверка

Ручная цепочка: доска → одиночная бороздка → повтор по месту в одном мазке →
новый мазок → явное наращивание → Undo/Redo → быстрый длинный мазок → линия →
штамп с цветами → сохранение собственного паттерна → reopen → F6.
Проверить тонкую деталь, край холста, шесть направлений граней, защищённую часть,
выделение, плотности 16/32 (не подразумевая их новую конверсию), секции сборки.
Save/discard не меняют чужие экземпляры. Тесты только fixtures/user://.
Ручной полный сценарий после UI ещё открыт; успешный layout test его не закрывает.

## Owners и границы

`ember_voxel_sculpt_workspace.gd`, sculpt model/actions, brush_profiles,
selection interaction, stamp/preset/panel, существующие stroke/terrain helpers
(найти через rg). Источник — `EmberVoxelModelResource`; сцена — `.tscn`;
mesh/collision/prefab производны. Переиспользовать чистую математику, не копировать
её в UI. Перед новой authoring schema определить owner и совместимость.

Не входят: набор россыпи из нескольких пресетов, масштабирование/деформация
штампов, следующие providers (цветы/камыш/прочие растения), сложные кривые, arbitrary Mesh/GLB import, новая
физика/renderer, вода, сюжет и перестройка всей мастерской.
Дно/открытая вода остаются следующим этапом большого EMBER_PRODUCT_PLAN.md.

После генеративных источников реализовано принятое двухэтапное выделение: сначала
рамка в плоскости начальной грани, затем вытягивание объёма внутрь по её нормали.
Это отдельная UX-feature поверх прежних selection owners, без новой schema и без
изменения геометрии до или после подтверждения.

Отдельный будущий `Быстрый режим` пока не включён в editor-wide contract. После
ручной приёмки надёжного режима можно проверить expert-вариант, где те же планы
применяются на отпускании LMB. Он не должен менять математику кисти, preview или
Undo owner и не должен незаметно ускорять опасные многошаговые операции.
